## 2. Key results / findings

Identified two structurally distinct failure modes in the PatchCore reproduction results:

**Type 1 — Detection failure (low I-AUROC)**

| Category | I-AUROC |
|---|---|
| pill | 0.968 |
| grid | 0.977 |
| capsule | 0.981 |

**Type 2 — Localization failure (low P-AUROC anomaly despite high I-AUROC)**

| Category | I-AUROC | P-AUROC (anomaly) |
|---|---|---|
| transistor | 1.000 | 0.929 |
| tile | 0.996 | 0.941 |
| wood | 0.990 | 0.937 |

Derived three hypotheses from these patterns:

| Hypothesis | Phenomenon | Implicated candidate |
|---|---|---|
| H2: Shape-biased features miss color anomalies | pill low I-AUROC | A (CLIP/VLM) |
| H3: Local aggregation misses global pattern breaks | grid low I-AUROC | C (Diffusion) |
| H4: Per-patch scoring misses spatial arrangement anomalies | transistor low P-AUROC | C (Diffusion) |

H2 → Candidate A; H3 + H4 → Candidate C. Candidate B is not implicated by any observed failure pattern in this 2D RGB dataset.
